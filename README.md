# Description

> Your introduction to 3D rendering on the GPU using OpenGL, Vulkan, or Metal. Through this small graphical project, you'll explore the core concepts of modern 3D graphics.

# Usage

```
go build
./scop path/to/file.obj
# or
go run scop path/to/file.obj
```

# Controls

- Up Down: Rotate object in the Y axies
- Left Right: Rotate object in the Z axies
- Z X: Rotate object in the X axies
- 1 3: Decrease/Increase scale
