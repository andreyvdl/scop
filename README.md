# Description

> Your introduction to 3D rendering on the GPU using OpenGL, Vulkan, or Metal. Through this small graphical project, you'll explore the core concepts of modern 3D graphics.

# Usage

```
go build
./scop path/to/file.obj
# or
go run scop path/to/file.obj
```

# Controls

- Up Down: Rotate object vertically
- Left Right: Rotate object horizontally
- Q E: Rotate object in depth
- 1 3: Decrease/Increase zoom
- A D: Move object horizontally
- W S: Move object vertically
- N M: Move object in depth
- Shift+V V: Vsync OFF/ON
- T: Toggle texture ON/OFF
- R: Reset parameters
- = -: Increase/Decrease FPS (limit between 30 and 120)
